{% comment %} Markup for the browser-driven camera push. Included only when the browser owns the transport. In that mode the server never renders the slot picker or the result card, because it never talks to the camera, so the shapes it would have rendered live here as inert templates and the client clones them. They are templates rather than strings inside the JavaScript so the markup stays described in one language and keeps matching slot-card.css, which is what both paths are styled by. A class renamed in the stylesheet breaks both together rather than only the path nobody tested. Every block mirrors the equivalent server-rendered partial: camera-slot-card -> recipes/_select_slot_partial.html camera-push-success -> recipes/_push_result_partial.html, success branch camera-push-error -> recipes/_push_result_partial.html, error branch {% endcomment %}
